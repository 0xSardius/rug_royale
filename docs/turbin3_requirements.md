# Turbin3 Capstone: Requirements (as given by Turbin3)

Copied verbatim from the cohort brief on 2026-10-05. Where this differs from the PRD, this file wins on *what gets graded*; the PRD still wins on *how the program works*.

## Overview

The capstone is your main project in this cohort that shows that you can use the technologies and concepts you've learned throughout this program and ship something real.

## Objectives

By completing this project, you will demonstrate your ability to:
- Design and implement an on-chain Solana program using Anchor
- Deploy a working program to devnet
- Write a complete and meaningful test suite
- Document your work clearly and professionally
- Ship a project from idea to deployed product

## Requirements

- The program must be deployed to devnet
- A complete set of tests should be passing on devnet
- A screenshot of the passing tests should be contained in the README
- The devnet Program ID of your program should be in the README
- Your architecture design/diagram should be well-documented in a README

## Presentation (Demo day)

THE DAY to showcase your program and present it live during the Demo Day week (starting Monday October 12th) - more info will be shared on this, but for now here is the overview:
- Each presentation under 5 minutes (time is very critical, lets respect everyone and keep it under the limit)
- Show what problem you solved and your solution (if applicable)
- Slides (max 5) might be useful OR frontend / UX if you have it (not mandatory)
- Include a demo of your devnet tests passing (you can use a recording if you want to ensure everything runs smoothly)
- Be ready to share your screen immediately when called

NOTE: This is a group project, and every member in the team should have an active contribution in building the project and preparing the presentation. However, at demo day presentation, it is not mandatory for each member to present.

## Submission

- Submit the link to the GitHub repository of the project with all above requirements completed
- Present the project at demo day (team presentation)
- Submit an individual reflection (google doc / pdf)

NOTE: The individual reflection should capture a short reflection (as the name indicates) of your individual contribution to the group project.
